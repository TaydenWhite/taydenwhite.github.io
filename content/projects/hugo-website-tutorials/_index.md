## Overview

During my 2024 data science internship at Johnson & Johnson, I spearheaded an initiative for interns to build and deploy their own static websites using Hugo and GitHub Pages. I produced the tutorial series below, with written guides and walkthrough videos, and used it to teach 20+ coworkers how to deploy a site of their own.

This website started as my own site from that initiative.

## What the series covers

1. **The building blocks:** what Hugo, Docsy, and GitHub each contribute.
2. **Build and deploy:** from a template repository to a live GitHub Pages site with GitHub Actions.
3. **Markdown basics:** the syntax used for almost all site content.
4. **Customizing content:** adding pages, menus, and a logo.

{{< callout >}}
The tutorials use Docsy, the Hugo theme this site ran on at the time. The site has since moved to a custom Hugo theme, but the workflow is the same.
{{< /callout >}}
